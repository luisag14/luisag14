## 🚀 Proyectos destacados

### 🛍️ Sistema de Gestión Empresarial — Isa Boutique

Aplicación web orientada a la administración y organización de procesos comerciales de una boutique.

**Tecnologías utilizadas:**
- PHP
- PostgreSQL
- JavaScript
- HTML y CSS

**Módulos del sistema:**
- Gestión de productos e inventarios.
- Registro de compras y ventas.
- Administración de proveedores.
- Control de pagos y existencias.
- Generación de reportes.
- Seguimiento de metas comerciales.

**Objetivo:** Facilitar la administración de información comercial mediante una solución tecnológica que contribuya a la organización y eficiencia del negocio.

### 💰 Sistema de Control Financiero

Proyecto de software orientado a la organización y administración de información financiera.

**Tecnologías utilizadas:**

- JavaScript
- HTML y CSS

**Funcionalidades del proyecto:**

### 🌐 Envision One — Plataforma SaaS Multi-Tenant

Proyecto académico de diseño y desarrollo de una plataforma web modular orientada a la gestión empresarial multisectorial.

**Áreas de trabajo:**
- Arquitectura de software multi-tenant.
- Análisis de requerimientos.
- Diseño de módulos empresariales.
- Modelado de bases de datos.
- Organización de información empresarial.
- Diseño de soluciones escalables.

**Objetivo:** Diseñar una plataforma que permita a diferentes tipos de negocios administrar sus procesos mediante módulos adaptados a sus necesidades.

**Estado:** Proyecto académico en desarrollo.
